# 16: Export tableur des exigences

**What to build:** Un membre exporte les exigences d'une initiative dans un fichier tableur, pour les communiquer aux parties prenantes (tâche BABOK 4.4).

**Blocked by:** 10 — Exigences

**Status:** ready-for-agent

- [ ] Tout membre de l'initiative peut exporter ses exigences au format Excel.
- [ ] Le fichier contient une ligne par exigence avec ses champs : référence, titre, énoncé, type, sous-type, statut, sources, besoins liés, exigence parente.
- [ ] Les en-têtes de colonnes sont dans la langue de l'utilisateur ; le contenu saisi n'est pas traduit.
