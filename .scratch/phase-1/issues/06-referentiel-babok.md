# 06: Référentiel BABOK (ADR-0012)

**What to build:** Tout utilisateur consulte le référentiel BABOK v3 livré avec l'application : les 6 domaines de connaissance, les 30 tâches, les 50 techniques et la correspondance entre tâches et techniques. Chaque élément porte son nom officiel en anglais et en français, un résumé rédigé pour ACTA dans les deux langues et son renvoi de section ; aucun extrait du texte de l'IIBA n'est reproduit.

**Blocked by:** 02 — Coque de navigation

**Status:** ready-for-agent

- [ ] Le référentiel est livré par migration, identique pour toutes les initiatives, en lecture seule pour tous, administrateur compris.
- [ ] Chaque élément a un identifiant stable (par exemple le numéro de section de la tâche), utilisé par les autres objets.
- [ ] Un écran de consultation présente les domaines, leurs tâches et les techniques associées à chaque tâche ; chaque technique liste les tâches qui l'utilisent.
- [ ] En français, le nom anglais de chaque élément est visible en info-bulle.
- [ ] Les éléments du référentiel sont accessibles par la palette Ctrl+K.
- [ ] Les résumés rédigés pour ACTA sont soumis à la responsable fonctionnelle et validés avant la livraison du ticket.
- [ ] Aucun texte de l'IIBA n'est reproduit (contrôle par la responsable fonctionnelle).
