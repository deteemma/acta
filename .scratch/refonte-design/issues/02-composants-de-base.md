# 02: Composants de base

**What to build:** Les éléments d'interface communs ont une seule apparence et un seul comportement dans toute l'application web.

**Blocked by:** 01 — Fondations visuelles

**Status:** à faire

- [ ] Maquette des composants et de leurs états dans le système de design ACTA (Claude Design), validée.
- [ ] Boutons : principal, secondaire, discret, danger ; états survol, focus, désactivé, en cours.
- [ ] Champs : texte, zone de texte, liste déroulante, case à cocher, groupe d'options ; libellé, aide, erreur.
- [ ] Badge de statut coloré selon sa famille de statut ; badge de compteur (alertes).
- [ ] Carte, liste dense (une ligne par objet), onglets, notice, info-bulle d'aperçu.
- [ ] Chaque écran existant utilise ces composants à la place des contrôles natifs.
- [ ] Navigation au clavier et focus visible sur chaque composant (WCAG 2.1 AA).
