# Statuts de tri

Les skills parlent de cinq rôles de tri canoniques. Ce fichier fait correspondre ces rôles aux chaînes utilisées dans ce dépôt. Comme les tickets sont des fichiers markdown (voir `issue-tracker.md`), le statut s'écrit dans la ligne `**Status:**` du ticket, pas comme une étiquette GitHub.

| Rôle dans mattpocock/skills | Statut dans nos tickets | Signification |
| --------------------------- | ----------------------- | ------------- |
| `needs-triage`              | `needs-triage`          | À évaluer par la responsable fonctionnelle |
| `needs-info`                | `needs-info`            | En attente d'informations de la part de l'auteur |
| `ready-for-agent`           | `ready-for-agent`       | Entièrement spécifié, prêt pour un agent autonome |
| `ready-for-human`           | `ready-for-human`       | Demande une intervention humaine |
| `wontfix`                   | `wontfix`               | Ne sera pas traité |

Hors tri, `done` marque un ticket réalisé et validé par la responsable fonctionnelle.

Quand un skill mentionne un rôle (ex. « appliquer le statut prêt pour un agent »), utiliser la chaîne correspondante de ce tableau.
