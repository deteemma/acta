# ADR-0009 — CI/CD : GitHub Actions, GHCR, déploiement manuel

- **Statut** : accepté
- **Date** : 2026-10-24

## Décision

GitHub Actions exécute le lint et la vérification des types. Sur une étiquette de version (semver), les images sont construites et publiées sur GHCR. Le déploiement est manuel, par un script `deployer.sh <application> <version>` qui fait une sauvegarde de la base, applique les migrations, puis démarre les conteneurs.

## Mise en œuvre dans le modèle

- `.github/workflows/ci.yml` : lint, types, tests des règles partagées.
- `.github/workflows/publier-image.yml` : sur `vX.Y.Z`, publie `ghcr.io/<propriétaire>/<dépôt>:X.Y.Z`.
- `deployer.sh` : sauvegarde `pg_dump` dans `sauvegardes/`, migrations, démarrage, attente de l'état « healthy ».
